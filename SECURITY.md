# Security Policy

## Supported Versions

Only the latest releases are supported with security updates. We encourage all users to run the latest stable version of Rodeo to ensure they have the latest security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of Rodeo seriously. If you find any vulnerability or security issues, please do not report them publicly through the GitHub issue tracker. Instead, follow these steps:

1. Send an email to **security@rodeo.dev** with details of the vulnerability.
2. Include a detailed description, steps to reproduce, and any proof-of-concept code or scripts if available.
3. We will acknowledge receipt of your report within 48 hours and work with you to coordinate a security fix and responsible disclosure timeline.

Thank you for helping keep Rodeo secure!
